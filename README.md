# Mentoria em Preenchedores Faciais — Dra. Fabiana Lopes

Landing page da mentoria presencial em preenchedores faciais conduzida pela
Biomédica Esteta Dra. Fabiana Lopes (CRBM 9108-5), em Rio do Sul/SC.

## Estrutura

```
index.html     página completa (HTML + CSS embutido, sem dependências de build)
img/           retratos profissionais otimizados para web
```

## Rodar localmente

```bash
python3 -m http.server 8080
```

Depois acesse http://localhost:8080

## Publicar

A página é estática e fica na raiz do repositório, então funciona direto no
GitHub Pages: em *Settings → Pages*, selecione a branch `main` e a pasta `/root`.
